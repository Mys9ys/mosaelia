# Карточка Яндекс Игр — Мозаэлия

Вставить в [черновик](https://games.yandex.ru/console). Картинки — из этой папки, не из скриншотов геймплея.

| Файл | Поле | Размер |
|---|---|---|
| `icon-512.png` | Иконка | 512 × 512 PNG |
| `icon-maskable-512.png` | Maskable иконка | 512 × 512 PNG, запас по краям |
| `cover-800x470.png` | Обложка | 800 × 470 PNG |

### Скриншоты

Реальный интерфейс, не обложка. Переснять: `npm run shots`.

В черновике: тип **Мобильные** → ориентация **портрет**, затем тип **Десктоп**. Минимум по 2 кадра на платформу. Геймплей должен занимать большую часть кадра — **howto и gallery2 в каталог не грузить**.

| Файл | Куда |
|---|---|
| `screens/mobile-play.png` | Мобильные, 1080×1920, 9:16 |
| `screens/mobile-win.png` | Мобильные |
| `screens/mobile-gallery.png` | Мобильные |
| `screens/mobile-menu.png` | Мобильные, по желанию |
| `screens/desktop-play.png` | Десктоп, 1920×1080, 16:9 — кроп поля, без пустых полей по бокам |
| `screens/desktop-win.png` | Десктоп |
| `screens/desktop-gallery.png` | Десктоп |

### Рекламные видео

Поле **Рекламные видео** в черновике. До 20 файлов, автостратегии сами выберут лучшие. Грузить пары 16:9 и 9:16.

Папка `ads/`:

| Файл | Длина | Что в кадре |
|---|---|---|
| `ads/ad-6s-play-16x9.mp4` / `ad-6s-play-9x16.mp4` | 6 с | плитки и рамка |
| `ads/ad-6s-win-16x9.mp4` / `ad-6s-win-9x16.mp4` | 6 с | почти готовая мозаика → «Картина готова!» |
| `ads/ad-10s-win-16x9.mp4` / `ad-10s-win-9x16.mp4` | 10 с | сборка + победа |
| `ads/ad-15s-16x9.mp4` / `ad-15s-9x16.mp4` | 15 с | партия до награды и старт второй картины |

## Общее

**Версия:** `0.1.0`

**Категории** (не больше двух): Головоломки, Казуальные

**Возраст:** 0+

**Игра переведена на:** русский

**Облачные сохранения:** да

### Теги

В консоли теги выбираются из списка. Набери и отметь, что есть:

головоломка, казуальная, логическая, пасьянс, мозаика, мердж, пазл, плитки, коллекция, галерея, спокойная, короткие сессии, одна рука, уютная, без гонки

Не ставить: три в ряд, match-3, таймкиллер, гиперказуал.

### Ключевые слова

70 / 100 символов, нижний регистр, через запятую:

```
мозаика, головоломка, плитки, мердж, пасьянс, картины, галерея, казуал
```
